# Odin Recipes

A basic recipe website built with HTML as part of The Odin Project Foundations course.

The site includes a homepage linking to three recipes: pancakes, chicken salad, and pizza. Each recipe page has an image, a description, an ingredients list, and step-by-step instructions.

Skills demonstrated: HTML boilerplate, headings, paragraphs, ordered and unordered lists, links (absolute and relative), and images with alt text.
